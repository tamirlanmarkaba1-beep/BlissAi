# blisschat 2.1.1 (Android · Kotlin · Compose · Material 3)

Уведомления

• В уведомлении теперь виден текст сообщения. Для фото, стикера, голосового и файла вместо текста подпись («📷 Фото» и т. п.). В секретных чатах текст по-прежнему скрыт.
• Канал уведомлений теперь высокого приоритета: со звуком, вибрацией и всплывающим баннером. Раньше уведомления могли приходить беззвучно.
• При выходе из аккаунта, переключении и добавлении второго аккаунта телефон отвязывается от старого. Раньше на него могли приходить пуши прежнего аккаунта.
• В Настройки → Уведомления появилась карточка «Проверить уведомления». Она проверяет разрешение, экономию батареи, регистрацию телефона и сервер, потом шлёт тестовый пуш. Есть кнопки «Тест на телефоне», «Настройки уведомлений» и «Батарея».
• В коде сервера (cloudflare-worker/worker.js) передаётся текст сообщения и есть проверка для теста.
