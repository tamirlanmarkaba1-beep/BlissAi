Частые вопросы

Коротко о работе приложения

Почему Android предупреждает об установке?

Приложение ставится напрямую из файла, а не из магазина, поэтому система просит подтверждение. Предупреждение появляется для всех APK вне Google Play.

Что с чатами после смены телефона?

Ключ шифрования хранится только на устройстве. На новом телефоне создаётся новый ключ, и старая переписка на нём не откроется.

Придёт ли уведомление о звонке?

Пока нет. Входящий звонок звонит, только когда приложение открыто.

Как проверить, что файл не подменён?

Контрольная сумма SHA-256 файла app-debug.apk:

d10475bb903e6714e39c2ad3817f9e4bfa6ac62d71b40d71efe38b4329a4bc1b
Есть ли версия для iPhone?

Нет, blisschat работает только на Android.
